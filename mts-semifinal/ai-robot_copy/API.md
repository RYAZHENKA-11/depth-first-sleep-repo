# Команды управления собакой — справочник

Список **разрешённых** команд и как их вызывать. Практика и запуск — в [INSTRUCTION.md](INSTRUCTION.md).

## Как вызвать команду

**Из терминала** (dry-run по умолчанию, `--yes` — выполнить):
```bash
./venv/bin/python 03_command.py <команда> [аргументы] --yes
```

**Из своего кода** (перед позами/движением один раз `go2.ensure_normal_mode(conn)`):
```python
await go2.sport(conn, "Sit")                            # поза/жест — по имени из таблицы
await go2.sport(conn, "Move", {"x": 0.3, "y": 0, "z": 0})   # движение
```

## Разрешённые команды

| Команда (CLI) | Имя в коде | Что делает | Нужен пол |
|---|---|---|:---:|
| `stand_up`   | `StandUp`       | встать в полный рост | ✅ |
| `sit`        | `Sit`           | сесть | ✅ |
| `rise_sit`   | `RiseSit`       | встать из положения сидя | ✅ |
| `stand_down` | `StandDown`     | лечь | ✅ |
| `balance`    | `BalanceStand`  | стойка с балансировкой | ✅ |
| `recovery`   | `RecoveryStand` | подняться после падения | ✅ |
| `hello`      | `Hello`         | помахать лапой | ✅ |
| `stretch`    | `Stretch`       | потянуться | ✅ |
| `wiggle`     | `WiggleHips`    | вилять бёдрами | ✅ |
| `heart`      | `FingerHeart`   | «сердечко» лапами | ✅ |
| `damp`       | `Damp`          | расслабить моторы (мягко осесть) | — |
| `stop`       | `StopMove`      | остановить движение | — |
| `move x y z` | `Move`          | ехать (см. ниже) | ✅ |

«Нужен пол» — собака должна стоять на полу со свободным местом вокруг.

### `move x y z` — параметры

| Параметр | Смысл | Пределы (зажимаются автоматически) |
|---|---|---|
| `x` | вперёд / назад, м/с | −0.6 … +0.6 |
| `y` | влево / вправо, м/с | −0.5 … +0.5 |
| `z` | поворот, рад/с | −1.0 … +1.0 |
| `--duration` | сколько ехать, сек | по истечении — автоматический стоп |

Примеры: `move 0.3 0 0` — вперёд · `move -0.3 0 0` — назад · `move 0 0 0.5` — поворот влево.
Собака едет сразу — всегда завершай `stop`.

# 🚫🔴 ЗАПРЕЩЁННЫЕ КОМАНДЫ 🔴🚫

> ## ⛔ НЕ ВЫЗЫВАТЬ
> **Эти команды ЗАБЛОКИРОВАНЫ на роботе и ЗАПИСЫВАЮТСЯ. Робот их не выполнит, а попытка видна организаторам.**

**Высокий риск травм и поломки:**

- 🚫 **САЛЬТО** — вперёд / назад / влево / вправо (FrontFlip, BackFlip, LeftFlip, RightFlip)
- 🚫 **ПРЫЖКИ** — FrontJump, FrontPounce
- 🚫 **СТОЙКА НА ЛАПАХ** — Handstand
- 🚫 **ПРЫЖКОВЫЙ БЕГ** — Bound
- 🚫 **ТРЮКИ** — Dance1/2, MoonWalk, CrossStep, OnesidedStep, Scrape, StandOut, Wallow
- 🚫 **ПРЯМОЕ УПРАВЛЕНИЕ МОТОРАМИ** (углы/моменты суставов) — недоступно

**Нужен трюк для показа — только под контролем организаторов, вручную, НЕ через это API.**

## Пример: последовательность

```python
import asyncio, go2

async def main():
    conn = await go2.connect()
    try:
        await go2.ensure_normal_mode(conn)
        await go2.sport(conn, "StandUp");  await asyncio.sleep(3)
        await go2.sport(conn, "Hello");    await asyncio.sleep(3)
        await go2.sport(conn, "Move", {"x": 0.3, "y": 0, "z": 0}); await asyncio.sleep(2)
        await go2.sport(conn, "StopMove")
        await go2.sport(conn, "Sit")
    finally:
        await go2.disconnect(conn)

asyncio.run(main())
```
